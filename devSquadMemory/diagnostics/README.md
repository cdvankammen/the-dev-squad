Diagnostics and dedupe tools

Files:
- merged_tools_deduped.json — merged tools array deduplicated by name (generated by devSquadMemory/tools/dedupe_tools.py)
- merged_summary.txt — short human-readable summary (counts and sample duplicates)
- copilot_tools_report.txt — original diagnostic summary copied from earlier memory bundle

How to run:

1) Generate merged payload and summary

```bash
python3 devSquadMemory/tools/dedupe_tools.py
```

2) Quick check script (exit code 0 = OK, 2 = duplicates)

```bash
bash devSquadMemory/tools/check_and_exit.sh
```

3) If duplicates are found:
- Inspect `devSquadMemory/diagnostics/merged_summary.txt` to see which names have multiple sources.
- Map any repo-origin names (paths under the repo) back to files and apply namespacing or remove duplicates.
- If duplicates only come from Copilot debug snapshots (external), add a pre-send dedupe in the code that builds the tools payload (see `devSquadMemory/tools/prevent_runtime_dupes.md`).

Notes:
- These artifacts live under `devSquadMemory/diagnostics/` per your request.
- I can add a small file-watcher or a launchd plist to run the check periodically if you want.
